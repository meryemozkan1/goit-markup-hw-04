# GoIT Markup Homework #4

This project is the fourth homework assignment within the GoIT Full Stack Developer program. It focuses on integrating SVG sprites (Icomoon & SVGO optimized), interactive hover/focus states with smooth transitions (`cubic-bezier`), complex background overlays, and semantic HTML structuring.

## 🚀 Live Demo
- [View Live Page](https://meryemozkan1.github.io/goit-markup-hw-04/)

## 🛠️ Technologies & Tools Used
- **HTML5 & CSS3:** Semantic markup, Flexbox, custom transitions, and pseudo-elements.
- **SVG Sprites:** Vector icons (`icons.svg`) managed via Icomoon and optimized with SVGO.
- **modern-normalize:** CSS reset/normalizer.
- **Google Fonts:** Raleway and Roboto integration.
- **Prettier:** Code formatting.
- **Git & GitHub:** Version control and GitHub Pages deployment.
